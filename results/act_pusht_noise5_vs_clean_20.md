# LeRobot 同种子对照评测

- 基线：`ACT-actions-10-clean`，原始数据 `act_pusht_replan10_holdout_20.json`
- 对照：`ACT-actions-10-noise5`，原始数据 `act_pusht_replan10_noise5_20.json`
- 任务：`pusht` / `0`；回合数：20
- 种子范围：2000–2019（由运行命令提供）

| 指标 | 基线 | 对照 |
| --- | ---: | ---: |
| 成功 | 1/20 | 1/20 |
| 成功率 95% Wilson 区间 | 0.9%–23.6% | 0.9%–23.6% |
| 平均回合最高奖励 | 0.445 | 0.435 |

- 最高奖励的平均配对差（对照 − 基线）：-0.010；中位数差：+0.001。
- 回合变化：10 个提高、9 个下降、1 个持平。
- 新增成功的种子：[2005]；失去成功的种子：[2001]。

## 解读限制

- 这是一组配对实验。若两次运行的真实起始种子或环境版本不同，配对结论失效；原始汇总文件本身不保存这些信息。
- 20 回合的成功率估计仍很不精确；奖励上升不能替代成功率和人工失败归因。
- 最高奖励是回合中任意时刻的最高值，不等于最后一帧的视觉接近程度或接触次数。
- 视频仅保存部分回合，CSV 中空白的视频路径或观察记录不代表该回合没有失败。

逐种子对照见 `act_pusht_noise5_vs_clean_20.csv`。
