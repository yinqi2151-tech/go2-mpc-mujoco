# Go2 MPC 步态评测报告（MuJoCo）

日期：2026-10-21 · 仿真器：MuJoCo 3.16 · 模型：MuJoCo Menagerie unitree_go2

## 结论

1. **移植成功**：原 MPC + WBC 控制器在 MuJoCo 中全部 32 组参数都能稳定小跑，没有一次摔倒；机身平均高度保持在 0.30–0.31 m。
2. **速度跟踪不足的原因已定位**：MPC 参考轨迹中的位置参考恒为 0（“留在原地”），而位置权重是速度权重的 10 倍。
3. **修正有效**：位置参考随期望速度推进后，16 组参数**全部**改善。平均速度跟踪从 60.5% 提升到 90.1%，速度误差（RMSE）从 0.145 降到 0.053 m/s。
4. **代价**：俯仰角波动增大。最大俯仰 RMS 从 1.75° 增加到 3.29°（出现在 0.5 m/s、占空比 0.55），仍在稳定范围内。
5. **步态参数**：支撑相占比越高，速度跟踪越好；在 0.5 m/s 时俯仰波动也随占比升高而减小；修正后最佳组合是占空比 0.65–0.70。目标速度越高，跟踪比例越低。

## 评测设置

| 项目 | 设置 |
| --- | --- |
| 控制周期 | 5 ms（200 Hz），物理步长 1 ms |
| MPC 求解 | 每 4 个控制周期一次（50 Hz），预测 20 步 × 0.02 s |
| 每次运行 | 12 s：落地稳定后站立 1.5 s，再切换小跑；速度指令从 0.15 m/s 逐步逼近目标 |
| 稳态窗口 | 速度指令达到目标的 97% 之后（约最后 5.8 s） |
| 参数网格 | 目标速度 0.2 / 0.3 / 0.4 / 0.5 m/s × 占空比 0.55 / 0.60 / 0.65 / 0.70 × 修正关 / 开，共 32 组 |
| 物理参数 | 摩擦系数 0.4（与原 Isaac Gym 配置一致）；去掉 Menagerie 的关节阻尼和摩擦 |

## 其他验证

| 检查 | 结果 |
| --- | --- |
| MPC 频率：原脚本 200 Hz 对比 50 Hz（目标 0.5 m/s，占空比 0.65，修正关） | 速度跟踪 56.7% 对比 55.2%，两种频率的行走效果接近 |
| MPC 单次求解耗时（单进程，Python + cvxpy + OSQP） | 中位数 45 ms，95 分位 64 ms，超过 50 Hz 的 20 ms 实时预算 |
| 不转换四元数顺序（MuJoCo 的 wxyz 直接当成 xyzw 用） | 0.5 s 内摔倒，说明这一步转换是必要的 |

## 局限

- MuJoCo 是确定性仿真，每组参数只跑一次；没有加外力扰动、地形变化或传感器噪声。
- 原代码把速度指令限制在 0.5 m/s 以内，所以没有测更高速度。
- 修正后在 0.5 m/s 仍有约 18% 的跟踪差距，原因尚未定位。
- 求解耗时说明当前实现不能直接上真机；需要热启动或 C++ 实现。
- 所有结论只在仿真中成立。
